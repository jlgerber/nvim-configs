# The NeoVim Help System

The help system is built around a series of help textfiles that 
come with neovim (just like vim).

## Activating help

To activate the help system, simply use the help command:

```
:help
```

## Closing the Help Window

To quite, simply type `:q`

## Getting help on a command

Simply type:

```
:help <COMMAND>
```

For example, to see what `dd` does, type `:help dd`

## Help on a Subject

To get help on a subject, do (have you guessed it) this:

```
:help <TOPIC>
```

For example type `:help count` to get help with count.

## Switching between the help window and editing window

```
<C-w><C-w>
```

## Navigating in the help window

You can go back and forward in the docs using 

- `<C-i>` - go forward in help window
- `<C-o>` - go back in help window
